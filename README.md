# Data Analyst & Machine Learning 

in this repository contains a collection of course projects & bootcamp competitions that 
i have compiled in the field of Data Analysis, and Machine Learning 

## Repository purpose
- documenting the learning process in the field of Data Analysis & Machine Learning
- Make a project portofolio for career needs

## folders structure

### Artificial_Intelligence
This is a course project at my college, about comparing the performance of KNN and 
logistic regression in predicting car purchases.

### Bootcamp_Data Analyst
This is a data analyst bootcamp organized by Ousean, the material includes learning 
to use Excel and the R language.

### Computer_Vision / Clasification_Object
This is a course project at my campus, namely computer vision, about the classification 
of 10 classes of objects, namely car logos.

### Human VS Spot AI Art
This is a project from my Student Activity Unit (UKM), the Google Development Group On Campus (GDGOC). 
The group created several competitions on human vs. AI painting classification using Python in a Kaggle Notebook.

### Kaggle_Competition
This project was implemented at the same UKM during the study period. The group also held another 
competition on the challenge of predicting customer churn in Kaggle Notebook.

### Machine_Learning_MandiriCamp
This project is an independent project, the materials used include learning about Decision Trees, Linear Regression, and Naive Bayes.
